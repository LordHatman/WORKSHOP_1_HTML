Miniövning: Workshopmeddelande

Vi skapar en personlig rubrik och ett meddelande som ändras beroende på om det är workshopdag.

  1. Vi frågar efter ett namn med prompt.
  2. Vi visar namnet i sidans rubrik med JavaScript.
  3. Vi sparar true eller false i en konstant.
  4. Vi använder if/else för att välja meddelande.
  5. Vi visar meddelandet med alert.

Kontrollera resultatet

Överst på sidan ska rubriken visa exempelvis Hej Kim. Ett meddelande ska också visas. Vi ändrar sedan värdet från true till false och laddar om sidan. Då ska det andra meddelandet visas.
